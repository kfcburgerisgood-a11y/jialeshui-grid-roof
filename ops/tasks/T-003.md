# T-003　M2 方盒驗證：中心距離、體積與零點表

- 里程碑：M2
- 分支：m2-body
- 背景：挑洞判定 M2 半通過；§6.2 步驟 2 要求確認封閉、尺寸、體積與剖面。缺體積與外／內／mid-wall 零點表（見 docs/m2_body_挑洞.md）。
- 要做：
  1. 用既有 `inputs/body_a.obj`（10000×6000×4000 mm）與 `Shell(T=300, side=1.0)`，在指定 voxel 下量測並寫表（不要改 design／openings／water／pores）。
  2. 量測並記錄（每個數值附 voxel mm）：
     - 封閉：is_closed True/False
     - bbox 尺寸（mm）
     - mesh 體積（mm³）與外殼實體體積（若可算）
     - **分清兩場**：`body_field`（實心 mesh 距離場）vs `body_shell`（Shell 後）
     - 幾何中心 (5000,3000,2000)：
       - 在 **body_field（實心）**：約 **−2000** mm（|誤差| ≤ voxel）
       - 在 **body_shell（殼後）**：腔內應為 **正**（挑洞先前探針 ≈+1600；勿用 −2000 驗殼）
     - 外表面／內表面（殼內側）／mid-wall 三點距離（對 **shell**；T=300 推定：mid-wall 約 −T/2＝−150；外≈0；腔內為正）
  3. 確認或重產剖面圖，註明色條正負（內負外正）
  4. 結果寫入 `docs/m2_body_verify.md`，並 append `runs.csv`（run_id 如 m2-003）
  5. 寫 `ops/reports/T-003.md`；小步 commit
- 不要做：改 body API 行為以外的模組；不定 T／b_min；不 push；不安裝無關套件；不跑歐郎 SubD（那是 T-004）
- 輸入：`inputs/body_a.obj`；T=300 mm（推定）；建議先 voxel=100 快速表，再 voxel=40 一筆（若時間允許；超過上限則 PARTIAL 並交付已有表）

  - [ ] 有體積數字（mm³）附 voxel
