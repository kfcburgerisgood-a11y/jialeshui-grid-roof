# T-010｜S 緩坡適合度規格

狀態：**規格／期望；非已驗證場**　執行：風場（規格）→ Claude（實作＋pytest）  
公式（總綱 §5.3）：`α = arccos(n · z)`；`S = clamp((α_max − α) / (α_max − α_min), 0, 1)`，單位 0–1  
座標：Rhino X=東、Y=北、Z=上；`z = (0,0,1)`；`n`＝殼**外**法線（單位）  
**不定 §8**；本卡只給煙測預設。

## 0. 角度約定

| 符號 | 意義 | 備註 |
|---|---|---|
| `α` | 外法線與鉛直上的夾角，`arccos(clamp(n·z, −1, 1))` | 0＝朝上水平；π/2＝豎直；π＝朝下 |
| `α_min` | S→1 的緩端 | 總綱未給數值 → **推定** |
| `α_max` | S→0 的陡端 | 總綱未給數值 → **推定** |
| `S` | 緩坡適合度 | 與風向／W／W_eff／H **無關**；禁止用 W 驅動 |

`n·z` 建議先 clamp 到 [−1,1] 再 `arccos`，避免浮點越界。

## 1. 煙測預設（推定；非作者定案）

| 參數 | 值 | 理由（推定） |
|---|---|---|
| `α_min` | **0 rad（0°）** | 朝上水平面視為最宜緩坡／種植參考 |
| `α_max` | **π/2 rad（90°）** | 豎直面視為不適合「緩坡」；pytest 對偶乾淨（水平 S=1、豎直 S=0） |

恒等式提示（僅預設 A）：α=arccos(n·z) 且 α∈[0,π] 時，`(π/2 − α)/(π/2) = 1 − (2/π)α`，**一般不等於** `n·z`。實作**必須走 arccos 公式**，pytest 用 §2.1 對照，勿偷換成 `max(n·z,0)`。

在本預設下：α=0 → S=1；α=π/4 → S=0.5；α=π/2 → S=0；α>π/2 → S=0（clamp）。

| 代號 | α_min | α_max | 取捨 |
|---|---|---|---|
| A（本卡預設） | 0° | 90° | 煙測清楚；豎直剛好歸零 |

### 2.1 單步解析（pytest 可直接 assert）

```
α = arccos(n·z)
S = clamp((π/2 − α) / (π/2 − 0), 0, 1)   # 預設 A
```

- `n=(0,0,1)` → S=1  
- `n=(1,0,0)` → S=0  
- `n=(0,0,−1)` → S=0  
- `n=(√2/2, 0, √2/2)` → S=0.5
