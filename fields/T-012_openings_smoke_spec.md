# T-012｜光孔反算煙測規格（最小）

狀態：**煙測鎖定／推定**　非基地驗證　執行：共匪鎖常數 → Claude 實作
依據：設計總綱 §5.4 光孔反算；M4 通過條件

## 公式（不變）

- 輸入：目標光斑 `y`（mm）、時刻太陽向 `s`（地面→太陽單位向量）
- 孔位：`x = y + λ·s`，`λ > 0`，孔軸 = `s`
- 檢核：自 `x` 沿 `−s` 打到目標面得 `y_actual`；`e = ‖y_actual − y‖ ≤ e_max`
- 同時刻多孔：軸互相平行（同 `s` 則必平行）
- `x` 須在可挖面（M=1）；不可打穿 keep

## 煙測常數

| 符號 | 值 | 狀態 |
|---|---|---|
| `e_max` | 100 mm | 推定 |
| `s` | T-009 CSV 夏至 09:00：約 `(0.6428, 0.1237, 0.7560)` | 沿用 fixture |
| 目標面 | z = 0 平面（或測試給定 `y_z`） | 合成 |
| 殼 | 測試用薄殼／方盒（mm） | 合成 |
