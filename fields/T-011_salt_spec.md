# T-011｜salt 鹽分場規格（最小煙測）

狀態：**規格／期望；非已驗證場**　執行：風場（規格）→ Claude（實作＋pytest）  
公式（總綱 §5.3）：`salt(x) = max(0, n·u_sea) × A_offshore(x) × C_wetdry(x)`  
範圍：建議正規化到 **[0,1]**（各因子皆 ∈[0,1] 時自然成立）  
**硬閘：禁止用 `W`／`W_eff`／`u_wind`／風花任何量驅動 salt**（總綱 §4／§5.4；迎風≠面海）。  
不定 §8；地形／蜂窩成因 **未查證**。

## 0. 物理敘事（推定，待查證）

總綱 §4：模型上破碎／多孔集中在**面海東南緣**，不是迎風東北端 → 鹽分主因**浪花打上面海側**，不是隨風運送。  
前提「地形為實測／掃描」**待確認**（§8.5）——本卡一律標**推定**，不宣稱基地鹽霧已驗證。

## 1. 符號與推定常數

| 符號 | 約定 | 煙測預設（推定） |
|---|---|---|
| `u_sea` | 陸→海單位向量；Rhino X=東 Y=北 | **東南 135°**：`(sin 135°, cos 135°, 0)` = **`(0.707107, -0.707107, 0)`** |
| `n` | 殼外法線 | 同 T-008／T-010 |
| `E = max(0, n·u_sea)` | 面海曝光 | 朝 SE 高、朝 NW 為 0 |
| `A_offshore` | 離岸距離衰減 ∈[0,1] | 見 §1.1 |
| `C_wetdry` | 乾濕循環 ∈[0,1] | 見 §1.2 |
| `salt` | `E × A × C` | 與風場計算路徑**零依賴** |

備選方位（不定案）：130°–150° 皆「約東南」；若歐郎鎖圖面方位再改常數，**勿改公式結構**。

### 1.1 離岸衰減 `A_offshore`（推定）

合成煙測**沒有真實海岸線**時，用局部假海岸：

- 海岸走向：西南–東北（與總綱「岩盤帶／風平行海岸」一致）→ 岸線方向約 `(cos 45°, sin 45°, 0)`＝`(0.7071, 0.7071, 0)`（沿 NE）
- 海在岸線**東南側**；點到岸線的有號距離 `d`（mm）：朝海為正、朝陸為負（或 clamp）
- 煙測簡式（選 **A**）：在合成盒上令岸線為平面／直線 `x + y = D_shore`（法線指向 SE＝u_sea）
  - 建議 `D_shore = 2000` mm（盒在陸側／近岸，中心原點時 `x+y` 最大在 SE 角）
  - `d = max(0, (p·u_sea) - d0)` 過於簡化；改用：

**預設 A（pytest 友好）：**

```
# 岸線：通過點 Q=(2000,2000,0)、法線 = u_sea（指向海）
# 有號離岸距（mm）：signed = (p - Q) · u_sea
# 海側 signed>0；陸側 <0
A = 1.0                           若 signed ≥ 0（已在「海／浪花帶」——合成測試少用）
A = exp(-|signed| / λ)            若 signed < 0（在陸側，離岸越遠越小）
λ = 3000 mm                       推定特徵長度
```

對 BOX0（±500）：整盒在 `Q` 陸側，`signed = (p−Q)·u_sea < 0`，A 隨位置緩變但仍 **>0**；面海側（SE 角）|signed| 較小 → A 較大。

**預設 B（更粗）：** 合成階段 `A ≡ 1`，只測 `E = max(0,n·u_sea)`；衰減留 SubD／真實地形另卡。  
本卡 Claude **先實作 A**；報告寫 λ、Q 推定。若測試不穩可退 B，但須在報告標「A 未測」。

### 1.2 乾濕循環 `C_wetdry`（推定）

正式應含潮汐／浪濺／日照蒸發——**資料未查證**。煙測預設：

| 方案 | 定義 | 何時用 |
|---|---|---|
| **C0（本卡預設）** | `C ≡ 1` | 最小煙測；把乾濕因子從本卡剝離 |
| C1 | `C = clamp(S, 0, 1)` 重用緩坡 | **不建議**：會綁 S，混淆鹽因 |
| C2 | 依高程 z 的簡單窗函數 | 另卡；需潮位資料 |

→ Claude 用 **C0**。報告寫「乾濕未建模＝1」。

## 2. 探針期望（BOX0 1000³ mm；C=1；A 用 §1.1 預設 A）

`u_sea ≈ (0.707107, -0.707107, 0)`

| probe_id | 點 (mm) | n | E=max(0,n·u_sea) | 期望（定性／半定量） |
|---|---|---|---|---|
| P1_SE_edge | 近 SE 角外法線朝 SE | n∥u_sea | **1.0** | salt 最高帶（同 A 時） |
| P2_NW | (−500,500,0) 或 n=−u_sea | n∥−u_sea | **0** | salt＝0 |
| P3_east | (500,0,0) n=+X | ≈0.707 | 中高 | E=√2/2 |
| P4_south | (0,−500,0) n=−Y | ≈0.707 | 中高 | 與 P3 同級（SE 對稱） |
| P5_north | (0,500,0) n=+Y | 0 | salt＝0 | n·u_sea<0 |
| P6_top | (0,0,500) n=+Z | 0 | salt＝0 | 水平不「面海」 |

**硬閘探針（與風正交）：**

| 斷言 | 做法 |
|---|---|
| H1 | 計算 salt **不得**呼叫／讀取 `W`、`W_eff`、`u_wind`、`WIND_DEFAULT`（靜態檢查或 API 隔離） |
| H2 | 同一幾何：改 `u_wind` 為任意值，salt 數值**不變** |
| H3 | ENE 迎風面（n≈u_wind）不必＝ salt 高峰；SE 面海高峰與 NE 迎風高峰**可分離**（BOX0：P3/P4 的 E 高於純北／純西） |

數值容差：E 用 `abs=1e-6`；A 依公式重算對照；salt∈[0,1]。

### 2.1 單步解析

```
u_sea = (√2/2, −√2/2, 0)
n_se  = u_sea                 → E=1
n_nw  = −u_sea                → E=0
n_e   = (1,0,0)               → E=√2/2 ≈ 0.707107
n_n   = (0,1,0)               → E=0
```
