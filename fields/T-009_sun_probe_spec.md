# T-009｜H_am／H_pm 日照探針規格

狀態：**規格／期望；非已驗證場**　執行：風場（規格）→ Claude（實作＋pytest）
座標：**推定** 22.006°N, 120.845°E（T-006）；時區 Asia/Taipei UTC+8（無夏令時）
公式（總綱 §5.3）：`H_am, H_pm = Σ_k V_k(x) × I[n·s_k > 0] × Δt`，單位 **h**

## 0. 約定（沿用，不改）

| 項目 | 約定 |
|---|---|
| `s_k` | 地面→太陽單位向量；只取 altitude > 0；Rhino X=東 Y=北 Z=上 |
| 轉換 | `fields_io.sun_vector_ground_to_sun(alt, az)` = `(cos alt·sin az, cos alt·cos az, sin alt)`；az：N=0 順時針 |
| `V_k` | 自 `p0 = p + ε·n_out`（ε=1e-3 mm，同 T-008）沿 **+s_k** 射線；撞同 mesh → 0（沿用 `wind_field.ray_mesh_occluded`） |
| `n` | 殼外法線 |

## 1. 取樣時刻表

| 項目 | 值 | 理由 |
|---|---|---|
| Δt | **0.5 h**（推定） | 冬至仍有 ~21 樣本、夏至 26；煙測夠分辨 am≠pm，射線成本低。正式可改 1/6 h |
| 取樣點 | 每格中點：`hh:15`、`hh:45`（當地鐘），altitude>0 才收 | 中點積分，避開日出日落邊界半格偏差 |
| am／pm 切分 | **當地太陽正午**（真太陽時 12:00）（推定）；樣本時刻 < 正午 → am | 對稱於太陽方位，東西面自然對偶 |
| 備選 | (a) 鐘點 12:00 CST：與正午差僅 ~5 分，本基地結果幾乎相同；(b) 方位角 az<180 → am：南回歸線以北夏至正午 az≈0/360 不穩，**不建議** |
| 煙測日 | **夏至 2025-06-21**、**冬至 2025-12-21** | T-009 卡建議 |

## 2. 探針期望（1000³ mm AABB，面中心點；凸體 V_k=1）

下表數值為「I[n·s_k>0] × 0.5 h 加總」的**期望參考**（風場用 CSV 試算，非 Claude 實作輸出）；pytest 以不等式為主，數值容差 ±0.5 h。

| # | 探針 | 日 | 期望 H_am | 期望 H_pm | pytest 斷言 |
|---|---|---|---|---|---|
| P1 | 東面 n=(1,0,0) | 夏至 | ≈6.5 | 0 | H_am > H_pm，H_pm == 0 |
| P2 | 西面 n=(−1,0,0) | 夏至 | 0 | ≈6.5 | H_pm > H_am；與 P1 鏡像 |
| P3 | 北面 n=(0,1,0) | 夏至 | ≈6.5 | ≈6.5 | H_am+H_pm > 0（§4：北面夏季有直射） |
| P4 | 北面 | 冬至 | 0 | 0 | 兩者 == 0 |
| P5 | 南面 n=(0,−1,0) | 冬至 | ≈5.5 | ≈5.0 | 兩者 > 0；夏至南面 == 0 |
| P6 | 頂面 n=(0,0,1) | 兩日 | = 該日 am 樣本×0.5 | = pm 樣本×0.5 | 夏 6.5/6.5，冬 5.5/5.0（取樣格不對稱，am≠pm 屬正常） |
| P7 | 遮擋：東面中心＋東側 blocker | 夏至 | < P1 | 0 | H_am(遮) < H_am(無遮) |

P7 建議幾何：主盒 [0,1000]³；第二盒 X∈[1500,2500]、Y∈[0,1000]、Z∈[0,3000]（同一 mesh 合併）。東面中心 (1000,500,500) 朝低角度晨光（如 08:00 alt 35.5°，需上升 ~714 mm 才越過 X=1500 → 撞）被擋；高角度時段仍可見。只斷言「下降且 ≥0」，不鎖精確值。

## 3. Claude 實作要點

- 純數學太陽位置即可（建議照搬本規格 NOAA 式，或直接讀 CSV 當 fixture）；若用外部庫須寫入 `ops/reports/T-009.md`。
- `s_k` 一律經 `sun_vector_ground_to_sun`（或同式）產生；altitude ≤ 0 丟棄；**不得**使用 Ladybug 太陽→地面向量而未反轉。
- 射線：起點 `p + 1e-3·n_out`，方向 +s_k，重用 `ray_mesh_occluded`。
- pytest 必須：(1) P1/P2 am/pm 分布不同；(2) P7 遮擋降 H；(3) H ≥ 0、單位 h；(4) §2.1 符號檢核。
- 報告寫 Δt=0.5 h、日期、座標（推定）、am/pm 定義（太陽正午）。
- 禁止宣稱：「日照場已驗證」「與 Ladybug 一致」「代表年日照」「含輻射量」。

## 4. 誠實／未驗證

- 座標 **推定**；未與 Ladybug sunpath 對過（無安裝）。
- 純幾何晴空直射：無雲、無天氣、無散射、無地形／周邊建物遮擋。
- EPW 本卡**未用**於日照／輻射；H 為「可直射時數」，非 kWh。
- 只兩個代表日；不代表全年分布，不定 §8。
- 太陽公式精度 ~±0.5°；正午附近 am/pm 歸屬可能隨 Δt 改變一格。
