# M2 方盒驗證表（T-003）

輸入：`inputs/body_a.obj`（測試 mesh A，10000×6000×4000 mm，角點在原點；不是 SubD）。殼：`Shell(field, T=300 推定, side=1.0)`。
腳本：`uv run python scripts/m2_verify.py <voxel> <run_id>`。原始數值：`docs/m2_verify_v100.json`。
距離場慣例：內負、邊界 0、外正。**分開兩個場**：`body_field`（實心 mesh 的距離場）與 `body_shell`（Shell 之後；殼 = s<0，腔與外部都 >0）。
